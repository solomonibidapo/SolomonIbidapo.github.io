Solo'sPicks

A sports prediction app that researches team stats on its own and publishes picks without any user input. It's built to reason from the numbers, not repeat the betting line.

  • Pick-first architecture using Poisson and Pythagorean win models
  • NRFI/YRFI logic for first-inning baseball picks
  • Layered data pipeline: live scores, lineup data, then targeted searches for pitcher form
  • WCAG-compliant frontend with a tab for each sport
